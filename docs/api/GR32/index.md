# GR32 Unit Reference

The `GR32` unit is the core foundation of the Graphics32 library. It contains primary data structures, 32-bit ARGB color definitions (`TColor32`), base bitmap classes (`TBitmap32`, `TCustomBitmap32`), and global pixel utility routines.
