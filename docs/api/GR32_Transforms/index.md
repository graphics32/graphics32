# Unit GR32_Transforms

The `GR32_Transforms` unit provides affine matrix transformations, inverse mapping, and geometric projection for bitmaps and vector paths.

---

## Classes

- `TAffineTransformation`: Manages 2D rotation, scaling, skewing, and translation matrices.
- `TTransformation`: Abstract base class for 2D spatial coordinate mappings.
