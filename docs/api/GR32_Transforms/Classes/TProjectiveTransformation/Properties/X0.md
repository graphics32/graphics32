## Description

Individual convenience properties exposing X and Y coordinates for destination quadrilateral vertices 0, 1, 2, and 3:
- Vertex 0 (`X0`, `Y0`): Top-Left corner.
- Vertex 1 (`X1`, `Y1`): Top-Right corner.
- Vertex 2 (`X2`, `Y2`): Bottom-Right corner.
- Vertex 3 (`X3`, `Y3`): Bottom-Left corner.
