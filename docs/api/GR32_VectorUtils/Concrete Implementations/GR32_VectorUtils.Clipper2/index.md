## Description

The `GR32_VectorUtils.Clipper2` unit provides `PolyLineBuilderClipper`, a [Clipper2](https://github.com/AngusJohnson/Clipper2) offsetter implementation of `TPolyLineBuilder` for polyline stroking and polygon inflating/offsetting.
