## Description

The `GR32_VectorUtils` unit contains vector construction utilities, geometric shape generators (circles, ellipses, arcs, stars, rectangles, rounded rectangles), polygon transformation and bounds routines, vertex reduction, clipping algorithms, and polyline stroke offset engines (`TPolyLineBuilder`).
