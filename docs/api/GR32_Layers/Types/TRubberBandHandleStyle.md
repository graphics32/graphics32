## Description

`TRubberBandHandleStyle` specifies the visual shape rendered for selection handles on rubberband layers.

## Values

| Value | Description |
| --- | --- |
| `hsSquare` | Rectangular / square selection handles. |
| `hsCircle` | Circular selection handles. |
| `hsDiamond` | Diamond / rotated square selection handles. |
