## Description

The `GR32_Polygons` unit implements vector rendering components and algorithms in Graphics32. It provides sub-pixel anti-aliased polygon filling, polyline stroking with customizable join styles and cap end styles, pattern and custom span filling (`TCustomPolygonFiller`), sub-pixel LCD text/graphics rendering, and modular polygon renderer registration.
