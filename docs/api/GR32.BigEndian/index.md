## Description

The `GR32.BigEndian` unit provides big-endian stream reading and writing routines.

Key capabilities provided by this unit include:

- **Big Endian I/O Helper**: [[BigEndian]] record structure containing static methods for reading and writing `Byte`, `Word`, `SmallInt`, `Cardinal`, and `Int64` values to/from `TStream` with automated byte swapping.
