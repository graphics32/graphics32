## Description

`Arc` appends a circular arc segment centered at point `P` with specified `Radius`, sweeping from `StartAngle` to `EndAngle` (given in radians).

Angles are measured clockwise starting from the positive X-axis (3 o'clock position). The arc points generated by `BuildArc` in `GR32_VectorUtils` are appended to the active path contour.

## Example

```pascal
var
  Canvas: TCanvas32;
begin
  Canvas := TCanvas32.Create(MyBitmap);
  try
    // Draw a semi-circular arc from 0 to Pi radians (bottom half)
    Canvas.MoveTo(200.0, 100.0);
    Canvas.Arc(FloatPoint(100.0, 100.0), 0.0, Pi, 100.0);
    Canvas.EndPath(False);
  finally
    Canvas.Free;
  end;
end;
```
