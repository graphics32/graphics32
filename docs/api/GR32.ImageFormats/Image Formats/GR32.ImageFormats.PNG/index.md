## Description

The `GR32.ImageFormats.PNG` unit implements image format adapters and readers for Portable Network Graphics (`.png`) files, through the VCL `TPNGImage` class.

::: info
The `GR32.ImageFormats.PNG` unit only supports Delphi/VCL.

For Lazarus/FPC, the `GR32.ImageFormats.PNG32` unit should be used instead.
:::
