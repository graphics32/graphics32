## Description

The `GR32_Geometry` unit provides essential 2D computational geometry routines for point manipulation, vector operations, line segment intersections, polygon containment tests, and coordinate calculations.
Most routines support overloaded variants for floating-point (`TFloatPoint`), fixed-point (`TFixedPoint`), and integer (`TPoint`) types.
