# Type TTextHinting

`TTextHinting` specifies hinting options for text rendering.

## Values

| Value | Description |
| --- | --- |
| `thNone` | Disable font hinting. |
| `thNoHorz` | Disable horizontal font hinting. |
| `thHinting` | Enable full font hinting. |
