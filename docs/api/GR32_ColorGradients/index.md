## Description

The `GR32_ColorGradients` unit provides linear, radial, conic, and polygon color gradient samplers for filled vector paths and bitmaps.

---

## Classes

- `TLinearGradientLookupTableSampler`: Linear color gradient sampler.
- `TRadialGradientSampler`: Radial color gradient sampler.
