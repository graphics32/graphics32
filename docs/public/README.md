# Graphics32 Documentation

Welcome to the Graphics32 **documentation** site repository.

The documentation is available here: [https://graphics32.github.io/](https://graphics32.github.io/)

---

### Note

- The content files in this repository make up a static web site that was **generated** automatically from the documentation source.

- This repository does **not** contain the documentation source files.
  The source files can be found in the `docs` folder of the Graphics32 repository: https://github.com/graphics32/graphics32/tree/[branch]/docs

- This also means that any documentation **edits**, **issues**, and **pull requests**, should be made against the Graphics32 repository.

- All editable pages in the documentation site contain inline links for editing the page via the Github web UI.
