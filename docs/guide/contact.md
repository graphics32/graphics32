# Contact

### Source code and documentation

  * GitHub project page: <https://github.com/graphics32/graphics32>
  * Documentation: <https://graphics32.github.io>


### Bugs and Features

Bugs reports and feature requests should be made at the Graphics32 GitHub project page:

  * Graphics32 GitHub issue tracker: <https://github.com/graphics32/graphics32/issues>


### General support

For general support please use one of the following options:

  * Graphics32 discussions on Github: <https://github.com/graphics32/graphics32/discussions>
  * StackOverflow: <https://stackoverflow.com/questions/tagged/graphics32>
    Remember to tag the question with #delphi and #graphics32 for best results.
  * Delphi-PRAXIS forums:
    * English: <https://en.delphipraxis.net/>
    * German: <https://www.delphipraxis.net/>
