# Requirements

Graphics32 currently supports the following compilers and platforms:

  * Delphi and C++ Builder version 10.2 and later
    * Windows (32-bit and 64-bit)
  * Lazarus 4.something.something (FreePascal 3.2.2) and later
    * Windows (32-bit and 64-bit)
    * Linux

Development and testing is primarily done on Windows using the later versions of Delphi and, occasionally, the latest version of Lazarus.
Generally, do not expect support for Delphi versions older than 10 years.

:::info
If you need support for prior versions of Delphi and Lazarus, use one of the older releases:
<https://github.com/graphics32/graphics32/tags>

Note that releases of Graphics32 prior to 1.9 doesn’t support Lazarus.
:::
