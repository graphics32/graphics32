# Requirements

Graphics32 currently supports the following compilers and platforms:

  * Delphi XE2 and C++ Builder XE2 and later
    * Windows (32-bit and 64-bit)
  * Lazarus 2.2.6 (FreePascal 3.2.2) and later
    * Windows (32-bit and 64-bit)
    * Linux



Development and testing is primarily done in the later versions of Delphi on Windows.

If you need support for prior versions of Delphi and Lazarus, use one of the older releases: <https://github.com/graphics32/graphics32/tags>
Note that releases of Graphics32 prior to 1.9 doesn’t support Lazarus.
